About Dominal Technology Jobs

Dominal Technology Jobs is an automated progressive web application built to streamline job discovery, rule-based role classification, and verified WhatsApp & LinkedIn distribution.


Key Highlights:

  • Automated JobSpy web scraper running every 2 hours.
  • Live Search Now scraper targeting LinkedIn, Indeed, Glassdoor.
  • Dual actions: 1-click WhatsApp message & direct LinkedIn App launch.
  • Deterministic rule-based sorting into IT, Non-IT, Electrical, and Sales.
  • Password protected via Vercel PASS environment variable.
  • Zero emojis policy across UI and templates.

Install on iOS (Apple Safari)

Follow these quick steps to add Dominal Jobs to your iPhone or iPad home screen:

  1. Open this website in Apple Safari.
  2. Tap the Share icon in the bottom Safari toolbar (the box with an upward arrow).
  3. Scroll down the share sheet and select Add to Home Screen.
  4. Tap Add in the top right corner.
